Software Libraries

The algorithms and techniques shown here are based on established methods or combinations of existing approaches, rather than ones I have developed entirely from scratch. Where possible, I have looked for existing code and used AI to help convert or adapt it into Python.

My main contribution has been organising these functions and algorithms into reusable software modules, which act as building blocks of code. Each module has clearly defined inputs, outputs and adjustable settings, allowing other programs to use it whenever that function is needed. Rather than rewriting the same code for different projects, one version can be shared and improved over time.

The libraries below are either already being used in my robotics projects or are planned for future use. This section focuses on the individual building blocks, while the Software Logic section shows how they are combined and used within larger programs.
